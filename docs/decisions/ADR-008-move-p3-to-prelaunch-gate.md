# ADR-008 · 将P3调整为公开上线前闸门

日期：2026-11-09。状态：人类定案，替代ADR-004及审查报告中“P3完成前不开始P5”的阶段限制；不改变I1–I13。

## 决定与顺序

暂不配置API key。OQ-017定案实施 → P5网页 → P6计费 → P7 staging → P3真实模型验证 → 公开上线。每阶段完成后写报告并停下等待人类确认；P5后在预览环境由人类试用。此次只授权推进到P5闸门，不能因后续阶段已列出而自动跨过人工确认。

P3的验证内容保留：届时由人类提供key与阶段费用上限，3次完整候选流程、首轮额外批准到记忆预览，记录逐岗位用量/缓存/费用/耗时/重试/截断、失败原文原因、3份完整候选及各岗位输出、首轮记忆预览全文。只观察现象，不修改提示词或vendor。P3通过需要人类阅读并决定模型及定价，不用开发测试推定真实质量。

## 无key期间的实现要求

准备12岗真实节奏的faux场景：3000–5000字中文正文，覆盖正常、重复/缺失锚点、超比例、length、漏提交和核验退回；延迟与逐字流速可配置。运行时增加record/replay，按稳定请求哈希回放，本地夹具不入Git；完整模型请求/响应和usage可录制，但凭据必须排除。无key时只跑faux/replay及本地注入测试，不调用真实上游。

所有待实测参数集中配置且在相关界面/文档标“待P3实测”：岗位maxTokens/超时、队列TTL余量；加价倍数、每美元点数与默认预留；赠送与套餐点数。保守占位值不构成价格或效果承诺。P6支付只做Mock及一个服务商沙箱适配器。

## 公开上线保护

P3前允许开发和staging，不允许公开注册或真实收费。生产注册必须邀请码；服务端用P3闸门与真实收费开关共同控制，真实收费开关默认关闭。缺省配置不能使任何收费路径生效；P3通过也不自动开启收费。公开上线仍需人类授权。

## 并行边界

另一线程在feat/backend-parallel拥有.github/、packages/pipeline/src/ideation/、packages/billing、构思侧worker任务及v4.1迁移。本线程负责P5前端和P6计费界面/接入，构思页面严格依docs/contracts/ideation-service.md；契约未推送先做章节页，不猜造对方接口。开始新大块前拉取origin/main；共享apps/worker/src/service.ts和packages/agents仅增量修改。

## 验收与理由

将真实质量/成本验收放到公开上线前，允许先验证产品闭环与界面；faux、录制回放或沙箱支付不能代替P3。各阶段报告明确未验证项。验证包括阶段规则一致性、服务端上线保护默认值、配置来源、真实节奏faux与回放、网页e2e及租户隔离。OQ-017已在前置提交通过306项测试；P5完成后再提交其完整验收报告并停下。
