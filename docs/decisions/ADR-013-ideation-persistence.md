# ADR-013：构思会话事务、事件与持久投递

日期：2026-11-10。依据契约 v1.1；不改变上游或 I1–I13。

会话、消息和幂等结果存平台表，不放入项目文件。所有服务先经 PostgresFS 所属项目事务，再校验会话/任务父子关联；幂等重放仍重查归属。原话仅存消息，运行请求和持久投递只存 ID/修订边界。现有 P4 ideation_messages/previews 没有完整会话契约，本批增量迁移，不丢弃历史行或改旧迁移。

构思事件有消息/预览等不同形状，使用独立 ideation_events 表，保留章节同样的提交后 ruwen_runs 通知、数据库游标与轮询重放方式。不会把任意 JSON 塞进章节 delta 文本。SSE 拉取有背压，每帧认证/归属，不把订阅时权限永久缓存。

受理消息、任务、幂等和 outbox 同事务，避免数据库提交后投递前崩溃丢任务。第二批消费者将 outbox 与 pg-boss 投递原子衔接，并沿用 role_runs 调用意图/完成检查点；未知响应不自动重发。第一批只提供 QUEUED 受理，不用虚假模型结果推进流程。

用户最新分工覆盖 PLAN 的历史边界：packages/billing 和冻结执行归主线程。构思仅提供同事务 beforeRun 接口，所有相关归属通过后、任务创建之前调用；拒绝全部回滚。无接入门时仅 faux 可发起，真实模式失败关闭。真实模型和收费仍受 P3 闸门限制。

主线程 P6 合并后补记：worker 适配器直接复用 @ruwen/billing 的 quoteRun/reserveRun/assertRunEnabled/finishReservation，同一项目事务受理并绑定预留，取消已排队任务释放。可选回调是额外策略，不替代平台计费/冻结检查；不修改 billing 核心或冻结逻辑。ADR 编号移至 013，避免与主线程 ADR-012 冲突。
