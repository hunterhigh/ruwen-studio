# ADR-016：前端设计变量与自托管宋体

状态：接受（2026-11-17，前端改版块 1）。

Windows 的系统宋体回退容易发虚，跨机器的稿面也不一致。原型使用思源宋体；产品不能依赖 Google Fonts 或境外字体 CDN，并需为大陆版及后续繁体文案保留空间。

采用设计规范中的桌面、稿纸、墨色和岗位色变量，旧变量暂作别名，块 11 再清理。朱砂动作只给批准印章；待决定标记使用浅朱砂。界面用系统黑体，稿面和标题用自托管的 Ruwen Serif（思源宋体 SC 400/600）。集中用词表与基础组件作为后续各块的公共入口，本块保持既有页面布局。

字体来自 Adobe Source Han Serif SC 2.003，保留完整字符覆盖。用 cn-font-split 一次性离线生成带 unicode-range 的 woff2 分片及 CSS，提交产物，以同源样式链接引入、font-display: swap 按需加载。完整产物约 58 MB，是仓库和部署体积；浏览器仅请求当前文字匹配的分片。保留 OFL 与版权信息，分包前将 name/CFF 中的字体名称改成 Ruwen Serif，遵守 Reserved Font Name。工具版本、来源提交及操作见 [字体说明](../../scripts/fonts/README.md)。

cn-font-split 与用于改名的 fontTools 只安装在忽略目录，均不进入项目依赖、构建步骤或运行时。页面不请求外部字体，不放宽既有 CSP。后续替换字符区域或本地化版本可重新生成产物，无需修改 API。

未选方案：系统宋体无法保证稿面质量；Google Fonts/CDN 增加网络依赖且不符合 font-src 'self'；整包 OTF 首次加载成本过高；只截取原型文字会使真实小说中的生僻字缺失；构建时自动分包会让每次构建依赖字体工具和源文件。
