# P5 人类试用指南

当前本机预览：**https://localhost:3000**。服务仅监听本机；首次看到自签名证书提示时，仅对此地址继续。数据会保存，刷新或重启不会清空。

## 启动与登录

预览已启动时直接打开地址即可。需要重新启动时，在仓库目录打开 PowerShell：

```powershell
cd C:\Users\admin\Desktop\agents\sat\ruwen-studio
pnpm install
$env:RUWEN_CANARY = [Convert]::ToHexString([Security.Cryptography.RandomNumberGenerator]::GetBytes(32))
pnpm dev
```

保持终端运行。填写任意测试邮箱，邀请码 **RUWEN-PREVIEW**，点击“发送登录链接”，打开“本浏览器的预览邮件”登录。此入口只供本机测试，不验证真实邮箱所有权。`preview@ruwen.local`可查看管理页；不要在这里输入真实支付或模型密钥。

## 建议试用路线

1. 书架→新建项目→演示项目（推荐先用演示资料，避免空白项目缺少就绪材料）。
2. 故事构思→新建会话→发送一个想法。读右侧通讯门，勾选确认，再“批准委托”。选择“文件变更”预览，读差异后单独批准；也可试拒绝、提出修改意见、新建/切换/关闭会话，以及刷新后继续。
3. 页底保留“编译章节”1，点击“编译章节情境”，选“章节情境”预览，阅读后批准。默认作用域来自演示项目；补充来源可以展开选择。
4. 章节写作→第1章、normal→开始写作。观察流式正文和岗位进度，阅读读者批注、编辑修改及两份核验；勾选确认后“批准正文，生成记忆预览”。逐文件读预览，再单独“批准并提交资料变更”。项目资料页可核对正文和世界资料。
5. 账户与用量：查看余额、预留、token/cache与账本，可试Mock沙箱购买；管理页可查看风险与审计，待核对预留须填写理由后结算或释放。仅测试数据，没有真实扣款。

## 已知限制与反馈

- 所有岗位使用faux固定剧本；3000～5000字演示章节用于交互验收，不代表真实模型质量。不同提问可能得到相同剧情；学习/表现等少见卡片另有HTTP夹具浏览器覆盖，不代表每种话题都能由当前faux主动触发。
- 当前使用v1.1运行接口。协调员引用原话可能仍出现替换提示；“选中文字逐字保留/写入文件”待v1.2后端及后续界面接入。
- 价格、套餐点数、预留、超时和模型上限均“待P3实测”；真实模型、SMTP/Google、搜索与Lemon外部沙箱未验收。P3、staging和公开上线均未进行，真实收费关闭。
- 风险冻结/人工解冻与审计已接入；协调员频率、一次性邮箱名单和用户自调每日限额等3.5细项尚未全部完成。
- 反馈请说明所在页面、操作顺序和预期；优先评价阅读/批准是否清楚、会话是否容易找回、进度与费用是否易懂。试用后再决定下一步，当前停在P5人类试用闸门。
