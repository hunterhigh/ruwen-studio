# P5 人类试用指南

原 faux 试用快照：**https://localhost:3000**。以下原试用说明对应该快照，它的服务与数据库保持不动；新增 DeepSeek 入口见末尾“真实模型试用”。服务仅监听本机；首次看到自签名证书提示时，仅对此地址继续。数据会保存，刷新或重启不会清空。

## 启动与登录

预览已启动时直接打开地址即可。需要重新启动时，在仓库目录打开 PowerShell：

```powershell
cd C:\Users\admin\Desktop\agents\sat\ruwen-studio
pnpm install
$env:RUWEN_CANARY = [Convert]::ToHexString([Security.Cryptography.RandomNumberGenerator]::GetBytes(32))
pnpm dev
```

保持终端运行。填写任意测试邮箱，邀请码 **RUWEN-PREVIEW**，点击“发送登录链接”，打开“本浏览器的预览邮件”登录。此入口只供本机测试，不验证真实邮箱所有权。`preview@ruwen.local`可查看管理页；不要在这里输入真实支付或模型密钥。

## 建议试用路线

1. 书架→新建项目→演示项目（推荐先用演示资料，避免空白项目缺少就绪材料）。
2. 故事构思→新建会话→发送一个想法。读右侧通讯门，勾选确认，再“批准委托”。选择“文件变更”预览，读差异后单独批准；也可试拒绝、提出修改意见、新建/切换/关闭会话，以及刷新后继续。
3. 页底保留“编译章节”1，点击“编译章节情境”，选“章节情境”预览，阅读后批准。默认作用域来自演示项目；补充来源可以展开选择。
4. 章节写作→第1章、normal→开始写作。观察流式正文和岗位进度，阅读读者批注、编辑修改及两份核验；勾选确认后“批准正文，生成记忆预览”。逐文件读预览，再单独“批准并提交资料变更”。项目资料页可核对正文和世界资料。
5. 账户与用量：查看余额、预留、token/cache与账本，可试Mock沙箱购买；管理页可查看风险与审计，待核对预留须填写理由后结算或释放。仅测试数据，没有真实扣款。

## 已知限制与反馈

- 所有岗位使用faux固定剧本；3000～5000字演示章节用于交互验收，不代表真实模型质量。不同提问可能得到相同剧情；学习/表现等少见卡片另有HTTP夹具浏览器覆盖，不代表每种话题都能由当前faux主动触发。
- 当前使用v1.1运行接口。协调员引用原话可能仍出现替换提示；“选中文字逐字保留/写入文件”待v1.2后端及后续界面接入。
- 价格、套餐点数、预留、超时和模型上限均“待P3实测”；真实模型、SMTP/Google、搜索与Lemon外部沙箱未验收。P3、staging和公开上线均未进行，真实收费关闭。
- 风险冻结/人工解冻与审计已接入；协调员频率、一次性邮箱名单和用户自调每日限额等3.5细项尚未全部完成。
- 反馈请说明所在页面、操作顺序和预期；优先评价阅读/批准是否清楚、会话是否容易找回、进度与费用是否易懂。试用后再决定下一步，当前停在P5人类试用闸门。

## 真实模型试用

前提：在**已经临时设置好 `DEEPSEEK_API_KEY` 的同一个 PowerShell 窗口**中，先完成人类亲自执行的 B 线程冒烟测试；保留该窗口，再进入下面的已准备 worktree。不要修改正在提供 3000 预览的旧仓库，不要把 key 写进 `.env`、命令参数、文档或聊天，也不要打印环境变量。

```powershell
cd C:\Users\admin\.codex\worktrees\ruwen-main-trial-next
pnpm preview:real
```

这条命令同时启动 web、worker 和独立本机数据库。访问 **https://localhost:3001**，邀请码 **RUWEN-PREVIEW**。首次仅对此本机地址接受自签名证书；输入测试邮箱，点击“发送登录链接”后打开“本浏览器的预览邮件”。没有 key 时启动器拒绝启动；web 与 worker 只继承启动窗口中的环境。3000 与 3001 的项目、登录 Cookie、队列及点数互相独立；重启后需重新登录，项目和点数保留。邀请码或登录次数限制出现时请按页面提示等待，不要修改 3000 数据库。

建议新建“演示项目”，按以下顺序逐步试用：

1. **构思对话**：新建会话，发送想法；看回答是否理解意图、重试后旧流式片段是否清掉。
2. **通讯门**：读干净委托与来源；确认没有擅自扩展意图，再勾选并批准。
3. **下游预览**：选择文件变更等卡片，逐项读差异；有问题先拒绝或提出修改意见，不直接批准。
4. **编译章节情境**：填写章节号，编译后选择“章节情境”；看事件、硬设定与授权来源是否正确，再批准。
5. **写一章**：章节写作页使用同一章节号开始；看正文连贯性、流式节奏、读者反应、编辑锚点替换、两份核验及失败说明。
6. **批准正文**：读完整候选稿后勾选批准；确认没有在批准前写入正典。
7. **记忆提交**：逐文件核对资料变更预览；只在状态变化、失效资料和正文相符时批准提交，再到项目资料页复查。

账户页显示真实 token/cache/usage 及沙箱点数。新账户赠送 **250000 沙箱点数**，按配置费率折合 USD 12.50 的用量记账额度；每次章节暂预留 100000 点，结束释放余量，预留不是售价。可串行试几章，不要同时发起多个章节。数值均待 P3 实测，实际费用由 **DeepSeek 预付余额**支付，以该余额作为实际费用上限；这里不提供自动充值。

费用参考来自 B 线程 `pnpm p3:smoke --plan --profile deepseek --max-usd 1.2` 的[完整离线计划](https://github.com/hunterhigh/ruwen-studio/pull/32)：固定演示轨迹的正文五岗位预算上界约 **USD 0.47/章**，加记忆预览约 **USD 0.55**；从构思对话到记忆预览的整条轨迹为 **USD 0.8595032321（约 0.86）**，provider calls=0。这按当前目录价格和岗位最大输出估算，含工具回合；实际正文、思考、额外修改和重试会改变费用，待 P3 实测，不是保证售价。B 的冒烟工具有 USD 1.2 硬上限；本网页不继承它的单次工具预算，实际费用上限依靠 DeepSeek 预付余额，沙箱余额不足也会阻止新运行。

不可用：联网搜索、所有支付/购买（包括 Mock 入口）、真实邮件登录与 Google 登录。本浏览器预览邮件不验证邮箱所有权，只供本机试用；本次试用不表示 P3 或公开上线验收通过。真实模型可能返回格式错误、超时或截断，按界面提示检查后再决定是否重试；重试也可能计费。

结束时在启动窗口按 **Ctrl+C**，等待 web、worker 和独立数据库退出，然后清除临时 key 并关闭窗口：

```powershell
Remove-Item Env:DEEPSEEK_API_KEY -ErrorAction SilentlyContinue
Remove-Item Env:REAL_MODEL -ErrorAction SilentlyContinue
Remove-Item Env:MODEL_PROFILE -ErrorAction SilentlyContinue
Remove-Item Env:MODEL_MODE -ErrorAction SilentlyContinue
Remove-Item Env:RUWEN_CANARY -ErrorAction SilentlyContinue
```

不要把清除操作替换为打印 key。停止 3001 不会停止原 3000 预览。
