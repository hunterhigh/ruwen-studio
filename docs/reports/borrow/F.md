# 块 F · 批注可处理

## 做了什么

- 预检以块 E 合并点 `4a790b4` 为基准。faux 运行详情保留 `qinggan-duzhe.reactions`、`wenxue-bianji.edits`、两类核验员 `issues` 的原数组顺序。两次读取一致。重核验换成当次核验岗位运行 ID，读者与编辑 ID 保持。
- 复核改版 #47 的 `locateEdits`。服务端按当前候选稿的唯一匹配和互斥区间处理一整批，复用 `applyRanges` 与块 E 的 `saveCandidateRevision`。发现缺失、重复匹配或重叠时返回相关 ID。
- 迁移 0206 保存意见状态和评价。运行详情以岗位运行 ID 和原数组零基索引返回 `annotations`。PUT 校验归属、CSRF、限流，可更新读者和核验意见状态及各类评价。意见反馈仅存数据库。
- 候选版本接口新增编辑撤销和恢复操作，在待批准状态把正文、版本审计、意见状态一起提交。保留实际哈希批准门和核验基准。已完成的意见数不参与批准条件。
- 管理后台的总体反馈按岗位完成日期筛选（UTC，默认近 30 天）。采纳和忽略率按全部意见计算，评价率按已评价意见计算。管理员读取进入现有后台审计。
