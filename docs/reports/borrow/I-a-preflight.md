## 测试结果

- 只读探针在演示夹具证实：缺投影会标记陈旧，缺资料包时登记失败，缺待晋升项时晋升失败。上游 Python `check` 同样报告 `no active packet`。Node 24.14.1/ICU 78.2 严格解码 UTF-8（含 BOM）、UTF-16 LE/BE、Big5、GB18030，繁体样本往返一致，非法 UTF-8 被拒。core 审计校验通过白名单摘要、拒绝附加文件名/哈希/章数/字数。
