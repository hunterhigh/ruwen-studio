# DeepSeek 本机试用入口（2026-11-11）

## 做了什么
- 新增 `pnpm preview:real`，一次启动 web/worker/独立本机 PG；3001、55329/ruwen_real_preview、Cookie、队列、TLS 目录及 Next 输出单独隔离。
- 复用 B 线程的进程环境凭据约束及 DeepSeek 模型路由；缺 key 时启动前拒绝，不载入 key 文件、不打印原始服务输出。
- 本机受限例外使用赠送沙箱点数结算真实 usage，所有购买/收费关闭；默认赠点 250000，章节预留 100000，余量照常释放。
- 补试用路线、离线费用估算、已知限制、Ctrl+C 与环境清理；ADR-012 记录本机计费例外。

## 测试结果
- `--faux` 浏览器演练通过构思→通讯门→下游预览→编译→章节→批准→记忆提交，并核对沙箱预留和 faux 运行记录；停机后 3001/55329 释放。
- 配置/账本选择/日志白名单/缺 key 预检通过；接入前全量 675 项和全部 23 项浏览器通过，接入共享检查后 288 项相关测试通过。最终 CI 结果见本 PR。
- 接入已合并 DeepSeek profile 后路由/预检 9 项通过；实际离线 `--plan` 复核 11 次预算约 USD 0.86，provider calls=0，无阻断步骤。

## 未完成与风险
- Codex 没有启动真实模型服务、读取真实模型 key 或执行 live 命令；服务演练显式使用 faux。人类在同一临时环境窗口先完成 B 冒烟，再启动此入口。
- DeepSeek 预付余额承担实际费用；沙箱点数只记账，既不是余额查询也不是独立 USD 硬上限。P3、定价及公开收费未验收。
- 联网搜索、支付、SMTP/Google 不开放；浏览器预览邮件不验证真实邮箱所有权。3000 试用快照及原数据库保持不动。
