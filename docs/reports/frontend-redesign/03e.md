# 块 3E · 作者修改候选稿

## 做了什么

- 从块 3T 的合并提交 `d11d52b` 接入纯文本稿纸、未保存保护、冲突刷新、只读版本与对比。应用内链接、切换稿面和运行使用确认框。关闭、浏览器刷新等由浏览器触发的离开使用原生离开提示。
- `runDetail` 的 `prose` / `run.candidateSha256` 是当前正文和哈希。版本序列来自 `run.candidateVersion` / `candidateVersions`。版本下拉只对你的各次修改单独编号，稿纸和核验标记采用保存序列的版号。
- 保存按块 E 的 POST revisions 传 `baseSha256` 和完整 `text`，201 返回版号与哈希。409 保留草稿并提示确认刷新。空文本、400、413、429 对应中文提示。GET revisions/:version 按接口要求携带 CSRF 令牌读取快照。改动处数是 TextDiff 的增加、删除与修改段落数之和。
- 核验基准使用 `verificationBasisSha256`。确认后 POST reverify 传 `expectedSha256`，202 返回独立任务 ID。重核验期间轮询运行详情，结束读入已保存的核验报告与岗位记录。批准继续用最新候选哈希与原有阅读条件。
