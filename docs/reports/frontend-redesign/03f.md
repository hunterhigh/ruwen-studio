# 块 3F · 可处理批注

## 做了什么

- 从 `cb82839` 接入块 F 的批注记录。使用 `runDetail.annotations` 的岗位、原数组索引和稳定 ID，重核验后使用当次核验意见。
- 批注统计阅读、编辑及两类核验意见，已采纳和已忽略或撤销计入进度。处理状态和有用评价独立，批准沿用正文与核验的阅读条件。
- PUT annotations 发送 `status` 或 `usefulness`，再次点同一评价发送 `null`。撤销与恢复使用当前候选哈希、`op` 和 `editIds` 走候选版本接口。定位冲突就近提示并可进入修改，不匹配的候选哈希用块 3E 的刷新流程。
- 页边定位条随稿纸可视范围调整。可定位的意见使用正文相对位置，已处理变淡，激活时加粗。宽度和定位通过客户端 ref 设置。
