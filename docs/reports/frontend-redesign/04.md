# 块 4 · 资料提交视图

## 做了什么

- 基于包含 #47 的 `main` `4d7387c`，沿用 `?run=…&view=memory`。资料提交使用既有 CSRF 客户端和批准/放弃接口。提交受理后与运行状态更新时刷新项目页头的「待你决定」。
- 四栏与下一章状态来自记忆维护员报告。逐文件差异来自 `memoryFiles`。已阅与预览哈希绑定，换哈希时清除勾选并提示重读。没有文件变更时可明确确认，下一章状态仍可阅读。
- 独立 `TextDiff` 位于 `apps/web/src/components/diff/TextDiff.tsx`。Props 为 `before: string`、`after: string`、`groupByHeading?: boolean`（默认 false，Markdown 文件传 true 按二级标题分组）。使用段落和句子两级 LCS，连续未改段可展开。长文本保留共同首尾，过大的未匹配区完整展示，限制 LCS 矩阵大小。块 3E 可直接传两段候选稿文本。

### 块 3 审阅遗留

- a. 缺少岗位记录时，用运行状态推断已完成岗位。已退回、失败、取消的运行用已保存的检查点推断，未留证据时保持原有显示。推断项显示 ✓ 和「用量见账户页」。[截图](04/legacy-roles.png)
- b. 「下一步」展示同一理由时，重写／退回构思的编辑决定条只显示决定名称。[截图](04/legacy-editor.png)
- c. 侧栏邮箱单行省略，完整地址在 `title` 中。[截图](04/legacy-email.png)
