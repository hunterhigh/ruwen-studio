# 块 5 · 故事构思

## 做了什么

- 构思页采用可各自滚动的会话栏、对话和收件箱。会话内联创建，关闭与任务取消沿用确认框。原始消息继续支持 Unicode 码点选区，流式回复沿用原 SSE 和重置逻辑。
- 六类预览按勘误呈现。文件差异使用块 4 的 TextDiff，表现激活仍校验审计、试写、阅读确认和版本哈希。拒绝确认可带理由。批准、拒绝与提修改意见成功后刷新项目待决定数。
- `?preview=` 选定预览，也支持通过现有读取接口定位其会话。`?compile=1` 展开编译表单。提交请求沿用现有客户端、参数及权限检查。

## 测试结果

- 保留持久化构思、流式重置、学习计划、表现激活、逐字保留及两次正典批准用例。浏览器验证深链、拒绝确认、六类卡片和 1180px 桌面宽度。四项全量结果见 PR。
- 项目内导航用例复现了页面在客户端接管前丢失“新建会话”点击的问题。会话创建和收件箱入口在可交互后启用，导航用例保留原断言。
