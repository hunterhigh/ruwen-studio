# 块 6 · 项目概览

## 做了什么

- 左栏展示五步进度与就绪检查。按章节运行状态显示下一步，逐条解释可识别的就绪错误。只在错误明确指向章节情境时提供编译深链。
- 右栏复用项目决定汇总，链接到候选稿、资料预览或构思选中的预览。章节表每章显示最近一次运行，较早运行可展开。已完成时可打开下一章的写作表单。
- 决定汇总每 60 秒轮询，隐藏时暂停，回到前台立即刷新。章节批准、资料提交及构思决定继续使用现有即时刷新入口。
- 与原型的差异来自现有数据。就绪通过时只显示一句确认，因为没有逐项清单。章题只在最近一次详情能从正文首行确定时显示，完成阶段也使用实际状态。

## 测试结果

- 单元覆盖全部章节运行状态、就绪错误的映射和 60 秒可见性轮询。浏览器走真实 faux 章节的正文与资料批准，验证构思与编译深链、章节历史和下一章对话框。资料不全使用与 core 输出一致的错误夹具。全量结果见 PR。
