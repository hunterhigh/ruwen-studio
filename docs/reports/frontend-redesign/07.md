# 块 7 · 书架

## 做了什么

- 书架读取 `GET /api/projects`，按 `created_at` 降序排列。书名搜索可和「全部 / 有章节待批准」筛选合用。创建日期沿用接口 ISO 时间戳的 UTC 日期，格式为 YYYY-MM-DD。
- 「等你批准」横卡选取排序后首个 `pending > 0` 的项目，「去处理」与封面卡均进入项目概览。网格角标直接使用 `pending`。可复用的 `BookCover` 用项目 ID 哈希选择六种 CSS 配色，题签书名保留八个字形，长标题在封面下方仍可阅读。
- 新建对话框保留空白与演示两种创建方式。ZIP 导入在对话框中显示不确定进度，失败时逐字展示 API 错误，可以重新选择同名文件。响应缺少错误文字时使用 v1.1 通用提示。
- 原型以三张横向列表卡展示示例进度、更新时间和演示标记。实现沿用设计规范的宋体、桌面色与批准色，按块 7 正文及 v1.1 改为封面网格、章节待批准横卡和真实创建日期。搜索、筛选、对话框和空态补足了原型书架中的占位交互。

## 测试结果

- 块 7 的 3 项 Playwright 用例通过，覆盖实际 API 创建、faux 章节产生待批准读数、筛选与搜索、键盘关闭后返回焦点，以及真实 ZIP 导入失败和导出再导入。测试另用拦截响应覆盖缺少错误文字的回退。
- 既有 Markdown 导入安全用例改走「导入 ZIP」文件选择器，仍验证脚本、外部图片和不安全链接的拦截。该用例已单独复跑通过。
- `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm test:e2e` 的完整结果见 PR 检查。复现本块产品截图可用 `FRONTEND_RED07_SCREENSHOTS=1` 运行 `apps/web/e2e/shelf.spec.ts`。
