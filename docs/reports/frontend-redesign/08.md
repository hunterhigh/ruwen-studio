# 块 8 · 项目资料

## 做了什么

- 资料页左侧 300px 按原项目目录分组，项目、人物、世界和故事默认展开。治理与 authoring-ruwen-v5 标为「系统记录」。搜索同时匹配文件名和完整路径。
- 从 `治理/资源注册表.json` 按路径取得状态、作用域与读取岗位。状态覆盖 `TRANSITIONS` 的五个值。岗位沿用共享角色标签。技术信息只展示当前文件的 SHA-256，默认折叠。
- Markdown 使用 SafeMarkdown 和宋体，章节正文沿用审稿桌稿纸样式。注册表用表格，账本按实际记录时间倒序，每条可展开。其他 JSON 和账本明细使用结构化键值视图。
- 原型资料页只有占位说明。本实现沿用原型的桌面色、稿纸色、宋体与岗位色，按块 8 正文补齐目录和阅读区。可用字段以 v1.1 勘误及实际接口为准。

## 测试结果

- 单元测试核对注册表状态全集、无有效时间的账本记录和 JSON 展示字段。浏览器通过真实文件 API 读取本机测试项目，覆盖七个页面状态、SHA-256 折叠和键值明细。
- 原有 Markdown 安全、章节正文读取、导航和读者诊断用例继续覆盖相关行为。四项全量命令结果见 PR CI。截图可通过 `FRONTEND_RED08_SCREENSHOTS=1` 运行 `apps/web/e2e/files.spec.ts` 复现。
- 本机 lint、typecheck、网页端 Vitest（153 项）及相关 Playwright（5 项）通过。
