# 块 9 · 账户与用量

## 做了什么

- 页头保留当前登录邮箱。左栏采用原型的 340px 卡片布局。正式点数与测试点数各自显示可用余额、运行中预留和 UTC 今日额度。调整上限在卡片内展开，支持允许范围校验、取消和恢复默认。
- 右栏按运行展开岗位明细，使用各组最早的岗位时间。空扣点显示「待核对」，岗位扣点账本行去重。可展开待核对预留，已处理的核对保留结果和理由。
- 购买在对话框内选择测试点数包。创建沙箱结账时账本和余额保持原值，确认模拟支付后才增加测试点数。不可结账及冻结状态沿用共享提示。登出所有设备仍由 ConfirmDialog 确认。
- 原型对比：保留两列、纸色卡片、宋体点数和岗位色。勘误要求将月度和单一余额改为两个点数池及 UTC 当日额度，运行标题改为项目名与实际时间，省略章节号、运行状态和预留时间。原型中的设备地名缺少数据，改为当前浏览器的登录状态。

## 测试结果

- 浏览器回归覆盖用量分组、空扣点、重复账本行、沙箱结账和入账、冻结、人工核对、上限变更与全设备登出。收费关闭使用现有账户响应的沙箱能力开关构造，其余截图来自预览环境的实际数据。
- 对七种状态下账户组件的渲染 HTML（包括购买对话框）执行大小写不敏感搜索，均没有 `USD`、`$`、`token` 或「缓存」。
- 四项全量检查 `pnpm lint`、`pnpm typecheck`、`pnpm test`、`pnpm test:e2e` 见 PR CI。设置 `FRONTEND_RED09_SCREENSHOTS=1` 运行账户、账本与风控浏览器用例可重拍页面截图。
