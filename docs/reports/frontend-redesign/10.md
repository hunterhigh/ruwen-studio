# 块 10 · 登录页

## 做了什么

- 登录页采用深墨和桌灰双栏，复用书架的 CSS 线装封面，题签「如文」。左栏按顺序说明创作流程，右栏负责登录。原型没有此页。
- 发信后移交焦点给确认状态。「换一个邮箱」清空邮箱并保留笔名和邀请码。预览入口、Google 可用性和链接有效期均来自服务端。登录页保持独立，九个受保护入口在未登录时跳转至此。

## 测试结果

| 接口返回 | 页面提示与位置 |
| --- | --- |
| POST 400 邮箱无效、403 邮箱服务不支持 | 填写完整地址或改用常用邮箱，显示在邮箱下 |
| POST 400 内容无效（表单已验证）、邀请码无效或用完 | 填写或核对邀请码，显示在邀请码下 |
| POST 400 正文无效、413 正文过大 | 核对或缩短填写内容，显示在发送按钮下 |
| POST 403 请求来源不符或校验失效 | 在登录页重试或刷新，显示在发送按钮下 |
| POST 429、404 路由找不到、500 或其他失败 | 429 使用可用的 `Retry-After` 或明确秒数。其他失败提示稍后重试，均显示在发送按钮下 |
| GET 404 无法访问、没有邮件或邮件过期、500 或其他失败 | 提示重新发送或稍后重试，显示在预览邮件按钮旁 |

- 两个接口的错误体目前是 `{error: string}`。Vitest 覆盖映射、字段位置和等待时间。Playwright 覆盖真实预览登录、字段保留、跳转和两种限流文案。生产页面的已发送截图模拟发信成功，Google 截图使用测试配置且未发起 OAuth。四项全量命令结果见 PR CI。
- 设置 `FRONTEND_RED10_SCREENSHOTS=1` 运行登录及生产浏览器用例可重拍。
