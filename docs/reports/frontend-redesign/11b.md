# 块 11b · 加载与错误状态

## 做了什么

- 八处用户视图采用静态灰块。客户端等待满 10 秒显示“加载得比平时慢，可以刷新重试”，刷新按钮重载当前页，卸载时清除计时器。错误改用朱砂浅底提示条，保留就近重试、修改输入或去处。统一清洗错误文本。导入 ZIP 失败继续显示服务端中文提示。下表为 1440×900 实际页面截图。G1 HTTP 原型画的是已加载的页面，骨架沿用其区域布局。原型没有实际登录页，登录骨架在本页登录请求送出后显示。

## 测试结果

- 单元测试覆盖错误文本清洗和 10 秒计时、卸载取消。八个 Playwright 用例逐页模拟慢响应与失败，检查 9,999 和 10,000 毫秒两个边界，确认失败后页面没有模拟的异常、路径和错误码。另测 ZIP 导出失败后可重试下载。完整检查见 PR CI。
