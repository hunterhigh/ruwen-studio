# 块 11c · 管理后台与 404

## 做了什么

- 管理后台保持运行概况和待核对预留两页，沿用块 1 的按钮和 ConfirmDialog。表格、提示条及纸色面板使用改版的设计变量。数值右对齐并用等宽数字，美元金额显示两位小数，提交的实际费用保留填写精度。
- `Admin.tsx` 的两处 `JSON.stringify` 展示已替换。失败任务改为岗位运行 ID、岗位、状态、开始时间表格。上线闸门改为 P3 验收、真实收费、注册方式表格。
- 404 使用居中的宋体稿纸和「回到书架」链接。HTML 原型未提供管理后台或 404 页面，本块沿用设计规范页的颜色、字体和按钮。

## 测试结果

- 管理组件和路由的 `JSON.stringify` 搜索无匹配。浏览器检查了失败任务、上线闸门和意见统计表格，以及金额的两位小数、右对齐、等宽数字。
- 普通用户访问两个管理页面均看到 404，两个管理 API 均返回 404。登录后访问不存在的项目 ID 也显示同一张 404 稿纸。独立的不存在路径返回 HTTP 404，书架链接可用。
- 浏览器回归校验了解冻和费用核对的确认流程。注入含内部路径的失败响应时，页面只显示就近的操作提示。四项全量命令结果见 PR CI。
- 设置 `FRONTEND_RED11C_SCREENSHOTS=1` 运行管理后台和计费浏览器用例可重拍截图。
