# P2 岗位、章节流程与本地CLI

日期：2026-11-06。P0已经人工确认；P1完成。P2没有额外人工闸门。

## 交付

- 12个RoleSpec、岗位提示词映射与12份提示词快照；按实际装配内容计算sha256。
- 新Agent上下文、输入字段白名单、严格结构化提交、一次纠正、总轮数上限、流式事件、用量、超时与取消。失败保存部分transcript和用量。
- 三级模型路由和岗位覆盖；真实调用必须同时具备REAL_MODEL=1与商用API环境密钥。faux为独立测试provider，不访问真实模型。
- 注册表/readers/project/hash约束的资源工具、限额诊断、批准后才出现的搜索工具和可替换Tavily适配器。
- LocalDirFS章节状态机、候选稿和记忆的两个独立批准门、原稿保留、事实/文学修改分开记录、核验失败退回编译员、陈旧哈希/重复批准拒绝、取消和角色成本记录。
- 原生Node CLI：chapter run / resume / status / cancel。终端展示候选稿、读者/编辑/核验输出、旧稿替换信息和逐文件记忆前后内容；必须输入APPROVE，EOF不批准。resume仅处理已有待批准运行，不是中断角色的worker续跑。

## 验证与限制

岗位48项测试覆盖每岗正常输出、缺失提交纠正、非法schema和轮数超限。另8项隔离/工具测试检查发送给provider的完整上下文、私有哨兵、新上下文、原话/委托互斥、注册表权限、外项目、诊断/搜索限额、混合工具批次、取消/超时、搜索协议和供应商错误密钥脱敏。

章节19项分支测试覆盖完整双批准、两个编辑退回分支、分离编辑记录、两类核验失败、前置检查、候选/资料包/情境陈旧、重复批准、非法记忆补丁、用户退回、项目归属和6个章节岗位各自运行时取消。CLI两个子进程测试验证完整双批准和EOF保持待批。

最终检查：lint、strict typecheck通过；13个测试文件、158个Vitest用例通过，包含原始Python36项基线和P1严格差分。Windows全量并发下完整双批准场景超过原先10秒测试上限，章节集成测试采用20秒上限；角色超时/取消上限保持独立验证。真实模型成本、文学质量、API可用性、生产租户认证和崩溃恢复均不属于这些faux测试的证明范围。

具体决定与本地恢复边界见[ADR-003](../decisions/ADR-003-role-isolation-and-local-pipeline.md)。下一步创建独立5.0演示夹具并执行P3真实模型验证；不得用faux结果替代真实成本表。
