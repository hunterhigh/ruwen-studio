在本项目`.env`本地配置：

```dotenv
REAL_MODEL=1
ANTHROPIC_API_KEY=填写商用API密钥
```

不要把密钥发到聊天或提交Git。配置后才能运行`pnpm benchmark:real`并补齐本报告的三次实际结果。
