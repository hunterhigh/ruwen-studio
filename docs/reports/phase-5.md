## 当前可用

- 本机HTTPS邮箱登录预览、服务端邀请码注册保护、可配置的Google与SMTP接入口；Secure/HttpOnly/SameSite=Lax Cookie。实际外部SMTP投递与Google账号回调尚未通过真实配置验收。
- 项目书架、空白初始化、演示项目、ZIP导入导出、就绪检查、最近运行与只读项目文件。用户提供的owner字段不能指定项目归属。
- 章节工作台：配置化逐字faux流、各岗位进度与记录费用、候选稿阅读、定位到正文的读者批注、原稿、编辑决定、分开的事实/文学修改和问题记录、情节/现实核验结论。
- 两次独立且明确的批准：服务端重新计算候选/记忆预览哈希；前端确认哈希仅用于拒绝陈旧批准，替换已有正文保留旧哈希检查。记忆变更按文件展示当前与预览；提交后通过文件历史读取原base版本，避免把新版本误作修改前版本。
- 手动退回与放弃。退回在同一事务内同步项目文件、pipeline_runs、pipeline_steps和通知；失败/退回不自动重写。已提交文学问题不因放弃消失。
- 账户已有余额/用量只读页、简化管理页与一次性邀请码。充值保持关闭；额度预留、结算、支付和webhook不在本增量实现，归并行后端/P6。
- 响应式桌面/390px移动端；正文纸页与侧栏批注；所有用户/模型展示内容走同一个安全组件。

启动方式、邀请码、证书提示、模式与限制见[本机预览说明](../web-preview.md)。根目录pnpm dev不会读取.env，固定faux/REAL_MODEL=0和关闭收费。本地状态在忽略的.local中保留。

## 安全自查（主线程S1-1至S1-4）

| 项目 | 实现与证据 | 状态 |
|---|---|---|
| S1-1统一安全Markdown | 唯一SafeMarkdown入口；跳过HTML、清洗节点、图片替换为文字，不发起图片请求；只保留绝对HTTPS链接且rel为noopener noreferrer nofollow；纯文本也在该组件转义。Biome禁止原始HTML注入，测试禁止其他组件引入Markdown渲染器。导入恶意文件的实际浏览器用例验证无脚本/图片/HTTP链接。 | 当前页面已验证 |
| S1-2 CSP/响应头 | HTTPS入口逐请求nonce；生产不含unsafe-inline或unsafe-eval；禁止框架、对象、base，限制来源，并设置nosniff、no-referrer、HSTS、权限、COOP/CORP。生产构建浏览器测试无CSP违规或页面脚本错误。 | 基线已验证；仍待人类设计3.3.4全文比对 |
| S1-3统一归属与CI漏测保护 | 项目/run/文件/SSE/导出先requireOwnership，跨租户与不存在均404；SSE循环重验身份归属。12条资源路由各有A→B 404用例；测试扫描路由注册表和route文件，新增参数缺测试元数据或绕开注册表会失败。所有私有路由另测未登录401；浏览器验证跨用户页面404。保护在pnpm test中，现有CI会运行，不修改并行线程拥有的.github。 | 当前路由已验证；构思新增接口接入时必须扩展同一覆盖 |
| S1-4 CSRF/Cookie/登录限流 | 所有应用POST要求可信Origin、非cross-site和HTTP-only __Host-CSRF Cookie对应的请求头；登录、批准、放弃、退回、邀请码与收费入口均覆盖。Cookie三属性通过真实登录响应检查；IP和规范化邮箱分别持久限流。HTTPS入口从连接取IP并HMAC证明，不信任任意XFF。Google发起按IP、回调在邮箱已知时再校验邮箱/IP。 | 当前应用接口已验证；外部Google配置仍需实测 |

认证库邮件验证和OAuth回调使用一次性token/state；不把带副作用的普通GET接口作为批准入口。绕过应用登录页直接调用认证库也不能注册未获邀请码授权的用户。生产预览邮件404，P3前收费403；不能靠隐藏按钮绕过。

人类的`docs/security/SECURITY-DESIGN.md`尚未出现在origin/main或origin/feat/backend-parallel，因此没有声称完成它的全文验收。ADR-009记录当前基线与此限制。开发工具自身会产生被CSP拒绝的样式；没有为此开启unsafe-inline，生产入口另行严格验证。

## 验证记录

提交前`pnpm lint && pnpm typecheck && pnpm test`全绿：28个测试文件、356项测试，包含原始Python36项、差分、I1–I13、PostgresFS、崩溃恢复、岗位faux、23项网页安全测试及逐字调度测试。全量用时202.52秒。`pnpm test:e2e`的生产构建成功，4项浏览器测试全部通过（1.8分钟）。无测试断言被放宽。

浏览器覆盖：注册→演示项目→逐步正文→候选批准→记忆预览→资料批准；核验失败退回、手动退回、放弃；ZIP导入导出；恶意Markdown不执行与不外发；跨用户API/SSE/导出/页面404；移动端无横向溢出；生产严格CSP与关闭预览邮件。

一次并行构建/测试期间C盘空间不足，两个原有文件系统测试报ENOSPC。未削弱断言或改产品逻辑；后续测试将本次TEMP/TMP指向D盘专用临时目录后重跑，原始失败场景已通过。该目录只用于本机执行，不构成仓库运行依赖。
