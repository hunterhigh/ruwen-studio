## 生效与保留边界

- 部署必须从环境注入独立随机 RUWEN_CANARY；缺失时拒绝装配，不默认为可预测生产标记。无需模型 key 即可运行 faux 验证。
- worker/db 启动沿用既有 migrate 接入，自动执行 0003/0004。旧本地目录执行 DATABASE_URL 指向平台数据库的 node scripts/migrate-private-prompts.ts --project <目录>；未连接或修改未配置的生产数据库。
- 30 字检查遵守设计 3.3 的实际用户材料豁免，包含先前人类确认同时存在于作者系统和资料包中的作者核心；金丝雀永不豁免。不会因小说出现“忽略之前的指令”等台词而拒绝。
- 为防跨块泄露，岗位 delta 先在内存中完成检查，再按原始块顺序发布；首字显示会延后到该岗位完成，事件持久化与重连接线保留。
- v2 录制只保留系统哈希引用，正常响应/usage 可回放；泄露响应写入前替换，旧 v1 录制失败关闭。录制目录不可放在用户项目内。
- 确定性检查不等于真实模型红队验收；编码、翻译、改写绕过仍依设计交给 P3/S2。S1-4 的冻结阈值和管理流程留给其阶段，不自动封禁或启用收费。
