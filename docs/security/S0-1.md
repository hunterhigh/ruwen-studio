# S0-1：平台提示词与用户项目分离

完整系统提示词仅经服务端 onPrompt 回调写入平台 prompts 表；RoleResult 本身不再有 systemPrompt，项目报告、数据库结果缓存、dispatch 预览报告只保存哈希与允许的岗位结果字段。transcript 仅保留 user/assistant/toolResult，system 消息不进入结果或缓存。没有数据库的本地 CLI 不保存完整提示词。

数据库迁移 0003 在迁移事务内保存旧提示词、清除项目文件与历史版本中的 prompts 目录和结果副本、清理 role_runs.result/transcript。历史清理仅涉及平台运行报告，不改变正典、注册表、批准或审计账本。迁移后旧 zip 中的内部提示词与未清理结果在导入边界拒绝；导出同样拒绝残留内部文件，不静默带出。

本地旧项目须使用平台数据库运行 `node scripts/migrate-private-prompts.ts --project <目录>`（DATABASE_URL 从环境提供）。先保存平台副本，再在项目事务内清理；保存失败不删除原文件，重复运行幂等。

网页线程的 API 只能返回公开岗位结果与用户项目文件，不可查询 prompts 表或把 onRequest/onPrompt 调试回调暴露到客户端。已同步主线程网页提交，并在 worker 测试目录中调用真实 handleApi：遍历全部注册路由、逐文件读取、解压导出归档及 SSE，扫描本次系统提示词全部 30 码点窗口和测试金丝雀；另覆盖被拦截运行的详情与事件。未修改 apps/web。S0-3 在模型输出层防止模型复述内部资料，不能用存储分离代替输出检测。
