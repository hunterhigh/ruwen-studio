# S0-3：输出泄露检测与账户风险事件

检测器使用本次真实装配的系统提示词，按 NFKC、移除 Unicode 空白与标点后逐个 30 码点窗口比较；仅豁免实际发送给岗位的用户材料、授权资源和搜索结果。未发送的多余输入字段不产生豁免；金丝雀永不豁免，且检测跨字段拼接。小说中的注入台词不按关键词拒绝。

提交工具执行前检查原始参数与助手输出；结构化岗位泄露立即失败、不自动纠正重试。协调员替换为设计规定的固定拒绝语。响应错误、thinking、transcript 同样检测和脱敏，失败仍保留实际 usage。为防止 SSE 先发出泄露前缀，模型 delta 暂存在岗位调用内存中，成功通过检查后才依原块顺序发布；失败不发布原始 delta。

security_events 只保存事件 ID、用户/项目/运行/岗位、类型、单次风险分和时间，不保存命中片段、系统提示词或金丝雀。与岗位结果和用量在同一个事务写入，按事件 ID 与 run/role/kind 去重；风险分由用户事件求和。固定内部拒绝与内容拒绝也记录为事件。冻结阈值、风控界面和管理员操作属于 S1-4，当前不自行实施。
