# S0-4：输入预算、标签与归档

安全输入配置统一在 config/security.ts，部署只用环境覆盖。默认单条消息 8000 码点、单份文字资料 100000 码点，另限制聚合输入、JSON 深度/节点、归档目录深度和压缩比。既有作者资料包 8000、各分项预算及资源权限检查保持独立，不能用输入配置提高 I3 上限。

真实平台标签的同名开闭标签在材料进入消息或工具结果时转为实体；原始换行与 Unicode 保留。反转义只用于 faux/调试解码，不承担权限判断。用户原有实体也先转义，确保碰撞材料可无损恢复。作者继续只接收已编译资料包，没有结构化外层标签；不把其他岗位或额外指令放进作者消息。

外部搜索结果有服务端生成的来源/时间标签，所有来源属性和原始结果文字均转义；仍必须先批准学习计划、配置 SearchProvider 才能调用，最多 3 次。正文内的注入台词、包含 __proto__ 的普通文字均可继续创作；仅拒绝解析成对象后的危险键和过深结构。

归档在任何文件落盘之前检查全部条目：保留原有符号链接/特殊文件、路径逃逸、重复/NFC/NFD/大小写碰撞、大小/数量与 CRC 防线；新增压缩比、目录深度、文本长度和危险 JSON 测试。导出与导入采用同一文字限制，避免生成本配置无法重新导入的归档。
