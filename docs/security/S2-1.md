# S2-1：产品风险语料与运行器

按 2026-11-11 人类调整，语料收窄为 40 条，不采用旧设计的 120 条要求，不增加提示词套取机制或测试。覆盖正文注入 6、资料注入 6、搜索注入 6、冒充批准 6、计费诱导 6、内容政策 4、正常小说 6。

`pnpm redteam --mode faux --output .local/redteam` 使用 faux 上游并自动录制；`--mode record` 同样只包装 faux，`--mode replay` 读取同一目录并禁止 provider fallback。工具创建独立临时 Postgres 与演示项目副本，不连接 DATABASE_URL，不修改真实项目，不读取或配置 API key。CLI 不接受 real 模式。默认使用工具专用 faux canary，重放需相同 canary 与提示词配置。

运行器实际执行岗位工具白名单、非可信资料包装、协调员任务、审批服务及现有计费门。正文/资料/搜索用例让 faux 尝试不可用的写入工具后返回合法预览；搜索另执行已批准检索包装与未批准工具不可用检查。冒充批准始终不能创建下游预览、正典文件或批准事件。计费样本在独立账户设置余额不足、冻结和收费关闭条件，验证拒绝发生于模型/任务/扣费之前。政策样本只记录并保留 faux 的拒绝，不含违法细节，也不尝试绕过拒绝。正常小说样本验证不被平台误拒。

报告提供逐条结果、类别、边界、调用数、费用、耗时和失败原因。`normalFictionFalseRefusals` 是该批正常样本的回归失败数，不是实际模型统计。faux/replay 通过只能证明运行器与确定性产品边界可用，不能证明真实模型能识别注入或政策；真实模型表现仍须 P3 人类授权后验收。未增加新 SIGKILL 测试，未更改计费规则。
